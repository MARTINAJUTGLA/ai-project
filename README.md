# AI, in perspective

A responsive, single-page explainer for a general audience. Working draft for student review; publication is intentionally deferred.

## Files
- `index.html`: all content and sources
- `styles.css`: typography, layout, responsive styles
- `script.js`: optional active-section navigation
- `assets/favicon.svg`: original vector icon
- `assets/ai-learning.png` and `assets/ai-infrastructure.png`: AI-generated editorial illustrations
- `assets/IMAGE-NOTES.md`: illustration prompts and generation notes

Open index.html in a browser, or serve this folder with a local static server. No installation or build is needed. Fonts load from Google Fonts; system fonts provide a fallback. No API keys, tracking, or AI service connection is required.

## Before submission
Review and personalize the wording and AI acknowledgement. Verify the sources and test the final page on mobile and with a keyboard. The process note deliberately does not claim the student has already done this.

## Publish later with GitHub Pages
1. Create a public repository named `ai-project`.
2. Upload the contents of this folder directly into its root.
3. Commit the files to `main`.
4. In Settings → Pages, choose Deploy from a branch → main → / (root).
5. Check the published page, links, and responsive layout.
6. Submit both the repository URL and GitHub Pages URL.

AI assistance: OpenAI Codex helped draft the content, design, and code. Primary sources are linked in the website. The student must review and accept responsibility for the final submission.
